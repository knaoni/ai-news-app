# 뉴스 수집기 기능 개발 워크플로우

AI 뉴스 수집기 앱에서 새 기능을 개발할 때 사용하는 명령입니다.
브랜치 생성부터 개발 시작 안내, 커밋, main 병합까지 전체 흐름을 진행합니다.
기능 이름(브랜치용): $ARGUMENTS

## 실행 순서

1. **현재 상태 확인**
   - `git status`로 현재 브랜치와 변경 사항을 확인해.
   - 현재 브랜치가 main이 아니면 경고를 보여주고, main으로 이동할지 사용자에게 물어봐. 사용자가 동의하면 main으로 이동해.

2. **새 브랜치 생성**
   - $ARGUMENTS가 입력되었다면 그 이름으로 브랜치를 만들어.
   - $ARGUMENTS가 비어 있다면, 어떤 기능을 개발할 것인지 사용자에게 물어보고, 답변을 바탕으로 영어 소문자-하이픈(kebab-case) 형식의 브랜치 이름을 제안해. 사용자 확인 후 그 이름으로 브랜치를 만들어.

3. **개발 시작 안내**
   - 브랜치 생성이 끝나면 '이제 개발을 시작하세요!'라고 안내해.
   - `CLAUDE.md`를 다시 읽고, 이 프로젝트의 기술 스택과 컨벤션(프레임워크, DB, 인증, LLM, Notion 연동, 커뮤니케이션 규칙 등)을 한국어로 간단히 정리해서 알려줘.

4. **작업 완료 처리**
   - 사용자가 '완료' 또는 'done'이라고 입력하면:
     - `git status`와 `git diff`로 변경된 파일 목록을 보여줘.
     - 변경 내용을 분석해서 커밋 메시지를 자동으로 제안해.
     - 사용자가 커밋 메시지를 확인(승인)하면 커밋을 생성하고, 현재 브랜치를 main에 병합해.

5. **작업 요약**
   - 병합이 끝나면 이번 작업에서 무엇을 했는지 한국어로 간단히 요약해서 보여줘.
